 Có trình bày nội dung thuật toán Xử lý ảnh số đủ rõ và đủ sâu.
 Tham chiếu, trình bày về plugin tương ứng trong Fiji/ImageJ để tham khảo, học hỏi thêm kinh nghiệm từ ứng dụng đã được chuẩn hoá.
 Các nhóm lập trình, cài đặt lại thuật toán bằng Python, Java hoặc ImageJ Macro.
 Có thể đánh giá kết quả bằng các chỉ số định lượng (bằng cả ImageJ/Fiji và code của nhóm), không chỉ quan sát bằng mắt.
 Trình bày quyển báo cáo (~30 trang) và presentation (~10 slides)
